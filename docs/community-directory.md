# Community Directory Draft

## Plugin ID

`toml-ini-viewer`

## Name

TOML INI Viewer

## Description

Open `.toml` and `.ini` files as a read-only config tree with search, source view, parse warnings, and render caps.

## Author

Viggo Meesters

## Repository

https://github.com/viggomeesters/obsidian-toml-ini-viewer

## Notes

The plugin is read-only and does not execute file contents, make network requests, or write normalized config files back to disk.
